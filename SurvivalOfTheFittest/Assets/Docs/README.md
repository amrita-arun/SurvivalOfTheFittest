# Survival of the Fittest

A short Unity 2D prototype about surviving modern dating — explore a dark maze, collect gems, face dating-themed encounters, and roll a fair six-sided die.

**Play:** Open `SampleScene` → Press Play → Start.

See [SETUP.md](SETUP.md), [ARCHITECTURE.md](ARCHITECTURE.md), and [PLAYTEST_CHECKLIST.md](PLAYTEST_CHECKLIST.md).
